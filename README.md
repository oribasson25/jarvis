# סוכן וואטסאפ – חבר AI בקבוצה

מערכת שמחברת מספר וואטסאפ ייעודי ל-Claude. מצרפים את המספר לקבוצה כמו כל חבר, והוא קורא את השיחה ומגיב לפי ההגדרות שקובעים בדשבורד.

## הפעלה

```bash
npm install
npm start
```

הדשבורד: http://localhost:3300

1. **מפתח Claude**: בלשונית "חיבור" מדביקים מפתח API (מקבלים ב-[platform.claude.com](https://platform.claude.com/settings/keys)). המפתח נבדק מול Anthropic ונשמר ב-`data/agent.db`. אפשר גם `ANTHROPIC_API_KEY` בקובץ `.env` (העתק של `.env.example`); מפתח מהדשבורד גובר עליו.
2. **מספר לסוכן**: סים/eSIM ייעודי. פותחים עליו וואטסאפ, הכי נוח דרך אפליקציית WhatsApp Business על הטלפון שלך (מספר שני לצד הרגיל).
3. **חיבור**: בלשונית "חיבור" סורקים את ה-QR מהטלפון של הסוכן (הגדרות ← מכשירים מקושרים), או מתחברים עם קוד.
4. **אישיות**: בלשונית "אישיות והתנהגות" כותבים את הפרומפט ובוחרים מתי הוא מגיב.
5. **מצרפים את המספר לקבוצה**. היא תופיע ב"קבוצות ושיחות", ושם אפשר להגדיר לה מצב והנחיות משלה.
6. **בודקים** ב"מגרש ניסויים" לפני שמשחררים אותו לחברים. שם שום דבר לא נשלח לוואטסאפ.

## מצבי תגובה

| מצב | מה קורה |
|---|---|
| כבוי | קורא ושומר הודעות, לא כותב |
| רק כשפונים אליו (ברירת מחדל לקבוצות) | מתייגים אותו, קוראים לו בשם/מילת קריאה, או עונים להודעה שלו |
| מחליט לבד | קורא הכל ומחליט מתי להשתתף, לפי "רמת מעורבות" |
| מגיב לכל הודעה | מגיב על כל רצף הודעות |

הסוכן יכול לענות (גם בציטוט של הודעה ספציפית), להגיב באימוג׳י, או לשתוק. רצף הודעות מהיר נאסף לתגובה אחת ("המתנה לפני תגובה"). בשעות שקט הוא עונה רק כשפונים אליו, ויש מגבלת פעולות בשעה לכל שיחה.

## איך זה בנוי

- `src/whatsapp.js`: חיבור כמכשיר מקושר דרך [Baileys](https://github.com/WhiskeySockets/Baileys) (QR / קוד צימוד, קבוצות, שליחה, אימוג׳י)
- `src/router.js`: מקבל כל הודעה, שומר, מחליט אם צריך תור, מאחד רצפים ומבצע את ההחלטה
- `src/agent.js`: בונה את הפרומפט ושואל את Claude. התשובה היא JSON מובנה: `reply` / `react` / `silent`
- `src/settings.js`: הגדרות כלליות והגדרות לכל שיחה
- `src/db.js`: SQLite מובנה ב-Node (`data/agent.db`): הודעות, שיחות, הגדרות, יומן פעילות
- `src/server.js` + `public/`: הדשבורד

החיבור לוואטסאפ נשמר ב-`data/auth`. מוחקים את התיקייה כדי להתחבר מחדש.

## מודל ועלויות

ברירת המחדל היא Claude Opus 5.5 עם עומק חשיבה נמוך, ואפשר לעבור ל-Sonnet 5.5 או Haiku 5.5 ב"הגדרות מתקדמות". במצב "מחליט לבד" כל רצף הודעות בקבוצה הוא קריאת API, כך שבקבוצה פעילה כדאי לשקול Haiku. ההיסטוריה נשלחת כך שהיא נשמרת במטמון (prompt caching) בין תורות. ב-Opus/Sonnet מופעל `fallbacks: "default"`: אם המודל מסרב לבקשה, היא מנוסה אוטומטית במודל חלופי.

## שימו לב

- **זה לא ממשק רשמי של וואטסאפ.** יש סיכון שהמספר ייחסם, לכן משתמשים במספר נפרד ולא מציפים בהודעות.
- הטלפון של הסוכן צריך להתחבר לאינטרנט לפחות פעם בשבועיים, אחרת המכשיר המקושר מתנתק.
- הסוכן עובד רק כשהתהליך רץ. בשביל 24/7 צריך מחשב שלא נרדם או שרת קטן. בשרת: `HOST=0.0.0.0` **יחד עם** `DASHBOARD_PASSWORD`.
- תמונות, הקלטות וסטיקרים מגיעים לסוכן רק כתיאור ("[תמונה] + כיתוב"). הוא לא רואה ולא שומע אותם.
